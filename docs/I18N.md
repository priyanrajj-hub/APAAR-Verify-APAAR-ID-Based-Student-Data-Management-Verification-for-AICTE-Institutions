## 2. Technical Terminology Glossary

To prevent mistranslations of statutory concepts under NEP 2020 and the DPDP Act 2023, the following standardized glossary governs all 12 languages:

| Term | English (`en`) | Hindi (`hi`) | Tamil (`ta`) | Telugu (`te`) | Urdu (`ur`) | Standard Context |
|---|---|---|---|---|---|---|
| **APAAR** | APAAR ID | अपार आईडी | அபார் எண் | అపార్ ఐడీ | اپار شناختی کارڈ | Automated Permanent Academic Account Registry (12-digit Lifelong ID) |
| **Consent** | Consent | सहमति | ஒப்புதல் | సమ్మతి | رضامندی | Explicit, time-bound, revocable consent under DPDP Act 2023 |
| **Audit Trail** | Audit Trail | ऑडिट ट्रेल | தணிக்கை சுவடு | ఆడిట్ బాట | آڈٹ کا پتہ | SHA-256 cryptographic append-only verification log |
| **Verified** | Verified | सत्यापित | சரிபார்க்கப்பட்டது | ధృవీకరించబడింది | تصدیق شدہ | Pass score $\ge 70$, Luhn checksum & registry match validated |
| **Needs Review** | Needs Review | समीक्षा आवश्यक | மறுஆய்வு தேவை | సమీక్ష అవసరం | نظرثانی درکار | Composite score $40-69$, minor phonemic/transliteration variance |
| **Rejected** | Rejected | अस्वीकृत | நிராகரிக்கப்பட்டது | తిరస్కరించబడింది | مسترد | Luhn failure, duplicate APAAR, or age/capacity bounds violation |
| **Institution** | Institution | संस्थान | நிறுவனம் | విద్యా సంస్థ | تعلیمی ادارہ | AICTE-approved engineering/polytechnic/management college |
| **Anomaly** | Anomaly / Mismatch | विसंगति / बेमेल | முரண்பாடு | అసమానత | بے ضابطگی | Cross-institution duplicate, ghost enrollment, or capacity spike |

## 3. Bidirectional (RTL) Layout Implementation for Urdu

Urdu is rendered using native Right-to-Left (RTL) mechanics:
1. **Dynamic Direction Attribute:** `<html lang="ur" dir="rtl">` automatically injected based on active locale cookie/preference.
2. **CSS Logical Properties:** Uses standard CSS logical properties instead of physical directions:
   - `margin-inline-start` / `margin-inline-end` instead of `margin-left` / `margin-right`.
   - `padding-inline-start` / `padding-inline-end` instead of `padding-left` / `padding-right`.
   - `inset-inline-start` instead of `left`.
3. **Table & Grid Flipping:** Data tables, progress meters, and wizard step indicators flip direction naturally without broken alignment.
4. **Font Pairing:** Noto Sans and Noto Nastaliq Urdu for clean, legible typography on mobile screens.

## 4. Key Parity Automation & CI Enforcement

The CI pipeline runs `scripts/check-i18n.js` on every pull request and push:
```bash
node scripts/check-i18n.js
```
- Traverses all keys in canonical `en.json` (96 nested keys).
- Compares key sets against all 11 Indic language files.
- Fails with exit code `1` if any key is missing or extra, preventing unlocalized string fallbacks in production.
